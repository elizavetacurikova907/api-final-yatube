# api_final
## Описание проекта:
Бэкенд соцсети, в которой можно публиковать посты с фотографиями или без, оставлять к ним комментарии, а также подписываться на других пользователей. Доступно подключение любого фронтенда с помощью API. Документация: redoc/
## Примеры запросов:
### Получение JWT-токена:
POST-запрос на адрес api/v1/jwt/create/. Тело запроса:
{
    "username": "string",
    "password": "string"
}
200 Удачное выполнение запроса:
{
    "refresh": "string",
    "access": "string"
}
400 Отсутствует обязательное поле в теле запроса:
{
    "username": [
    "Обязательное поле."
    ],
    "password": [
    "Обязательное поле."
    ]
}
401 Переданная учетная запись не существует:
{
    "detail": "No active account found with the given credentials"
}
### Добавление новой публикации в коллекцию публикаций. Доступно для зарегистрированных пользователей.
POST-запрос на адрес api/v1/posts/. Тело запроса:
{
"text": "string",
"image": "string",
"group": 0
}
Ответы:
201 Удачное выполнение запроса:
{
    "id": 0,
    "author": "string",
    "text": "string",
    "pub_date": "2019-08-24T14:15:22Z",
    "image": "string",
    "group": 0
}
400 Отсутствует обязательное поле в теле запроса:
{
    "text": [
    "Обязательное поле."
]
}
401 Запрос от имени анонимного пользователя:
{
    "detail": "Учетные данные не были предоставлены."
}

## Как запустить проект:

Cоздать и активировать виртуальное окружение:

```
python3 -m venv env
```

* Если у вас Linux/macOS

    ```
    source env/bin/activate
    ```

* Если у вас windows

    ```
    source env/scripts/activate
    ```

```
python3 -m pip install --upgrade pip
```

Установить зависимости из файла requirements.txt:

```
pip install -r requirements.txt
```

Выполнить миграции:

```
python3 manage.py migrate
```

Запустить проект:

```
python3 manage.py runserver
```
